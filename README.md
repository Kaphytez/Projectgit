# Projectgit

## Описание:

Проект Projectgit - это консольное приложение на Python для обработки финансовых транзакций. Он позволяет читать данные о транзакциях из указанного пользователем файла (JSON, CSV или Excel), фильтровать их по статусу, сортировать по дате, генерировать описания, маскировать конфиденциальные данные счетов и карт, а также конвертировать суммы транзакций в рубли, используя внешний API для получения курсов валют. Для облегчения отладки и мониторинга реализовано логирование действий в файлы `logs/main.log`, `logs/masks.log`, `logs/utils.log` и `logs/external_api.log`. Код проверяется с помощью линтера Flake8.

## Установка:

1.  Убедитесь, что у вас установлен Python 3.7 (или выше) и Poetry ([инструкция по установке Poetry](https://python-poetry.org/docs/#installation)).
2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Kaphytez/Projectgit.git
    cd Projectgit
    ```
3.  Установите зависимости проекта с помощью Poetry:
    ```bash
    poetry install
    ```
    Эта команда создаст виртуальное окружение (если оно еще не создано) и установит все необходимые пакеты из `pyproject.toml`.
4.  Активируйте виртуальное окружение, созданное Poetry:
    ```bash
    poetry shell
    ```
5.  Создайте файл `.env` в корне проекта (можно скопировать `.env.example`, если он существует в репозитории) и добавьте туда свой API-ключ для курсов валют (получите его на сайте [https://apilayer.com/marketplace/exchangerates_data](https://apilayer.com/marketplace/exchangerates_data) или аналогичном сервисе):
    ```
    EXCHANGE_RATES_API_KEY=YOUR_API_KEY
    EXCHANGE_RATES_BASE_URL=https://api.apilayer.com/exchangerates_data/
    ```
    **Внимание:** Никогда не храните API-ключи в коде! Используйте переменные окружения.

## Использование:

1.  Убедитесь, что вы находитесь в активированном виртуальном окружении (`poetry shell`).
2.  Подготовьте файл с транзакциями (например, `operations.json`, `transactions.csv`, `transactions_excel.xlsx`) в соответствии с ожидаемой структурой данных. 
3.  Запустите приложение:
    ```bash
    poetry run python main.py
    ```
4.  Приложение запросит путь к файлу с данными. Введите полный или относительный путь к вашему файлу.
5.  Следуйте инструкциям в консоли для выбора операций:
    *   Вывести последние 5 транзакций (отсортированных по дате).
    *   Фильтровать транзакции по валюте.
    *   Сгенерировать номера карт (ввод диапазона).
    *   Вывести описания всех транзакций.
    *   Узнать текущий курс валюты (используется внешний API).
    *   Выйти.

### Ожидаемая структура данных

Файлы с транзакциями должны иметь следующую структуру:

*   **JSON-файл** (например, `operations.json`): Список словарей, где каждый словарь представляет транзакцию с полями:
    *   `id` (целое число): Идентификатор транзакции.
    *   `state` (строка): Состояние транзакции, например, `EXECUTED` или `CANCELED`.
    *   `date` (строка): Дата транзакции в формате ISO (например, `2019-08-26T10:50:58.294041`).
    *   `operationAmount` (словарь): Информация о сумме операции.
        *   `amount` (число): Сумма транзакции.
        *   `currency` (словарь): Информация о валюте.
            *   `name` (строка): Название валюты (например, "Доллар США").
            *   `code` (строка): Код валюты (например, `USD`, `RUB`).
    *   `description` (строка): Описание транзакции.
    *   `from` (строка, опционально): Отправитель (например, `Maestro 1596837868705199` или `Счет 64686473678894779589`). Может отсутствовать.
    *   `to` (строка): Получатель (например, `Visa Classic 6831982476737658` или `Счет 35383033474447895560`).

    ```json
    [
      {
        "id": 441945886,
        "state": "EXECUTED",
        "date": "2019-08-26T10:50:58.294041",
        "operationAmount": {
          "amount": "31957.58",
          "currency": {
            "name": "руб.",
            "code": "RUB"
          }
        },
        "description": "Перевод организации",
        "from": "Maestro 1596837868705199",
        "to": "Счет 64686473678894779589"
      }
    ]
    ```

*   **CSV/Excel-файлы** (например, `transactions.csv`, `transactions_excel.xlsx`): Таблица с колонками, соответствующими *основным* полям JSON: `id`, `state`, `date`, `amount`, `currency_code`, `description`, `from`, `to`. Обратите внимание, что `amount` и `currency_code` здесь могут быть на верхнем уровне для простоты табличного представления. Приложение должно корректно обрабатывать чтение из этих форматов.

    Пример CSV:
    ```csv
    id,state,date,amount,currency_code,description,from,to
    441945886,EXECUTED,"2019-08-26T10:50:58.294041",31957.58,RUB,"Перевод организации","Maestro 1596837868705199","Счет 64686473678894779589"
    ```

    *Примечание:* Уточните в коде (`src/utils.py`), как именно происходит чтение CSV/Excel и какие точно колонки ожидаются.

## Файлы проекта

В корневой директории проекта находятся следующие основные файлы и директории:

*   `main.py`: Основной файл приложения.
*   `.env`: Файл для переменных окружения (необходимо создать).
*   `pyproject.toml`: Файл конфигурации проекта и зависимостей для Poetry.
*   `poetry.lock`: Файл с зафиксированными версиями зависимостей.
*   `README.md`: Этот файл.
*   `.flake8`: Конфигурация линтера Flake8.
*   `data/`: Директория для *примеров* файлов с данными (не обязательно используется для запуска).
*   `logs/`: Директория для файлов логов (`main.log`, `external_api.log`, `masks.log`, `utils.log`).
*   `src/`: Директория с исходным кодом модулей.
*   `tests/`: Директория с тестами.

В директории `src/` находятся следующие модули:

*   `__init__.py`
*   `decorators.py`: Модуль с декораторами (предположительно для логирования или других сквозных задач).
*   `external_api.py`: Модуль для взаимодействия с внешним API курсов валют. Логирование в `logs/external_api.log`.
*   `generators.py`: Модуль с генераторами данных (например, номеров карт).
*   `masks.py`: Модуль для маскировки конфиденциальных данных. Логирование в `logs/masks.log`.
*   `processing.py`: Модуль для фильтрации и сортировки транзакций.
*   `utils.py`: Модуль со вспомогательными функциями (чтение данных из файлов и т.д.). Логирование в `logs/utils.log`.
*   `widget.py`: Модуль для форматирования данных (например, дат, номеров карт/счетов) перед выводом.

## Тестирование

Этот проект использует `pytest` для автоматизированного тестирования. Тесты организованы в папке `tests`. Для проверки стиля кода используется `Flake8`.

### Модульное тестирование

Основные компоненты:

*   `tests/test_decorators.py`: Тесты для `src/decorators.py`.
*   `tests/test_external_api.py`: Тесты для `src/external_api.py`.
*   `tests/test_generators.py`: Тесты для `src/generators.py`.
*   `tests/test_main.py`: Тесты для `main.py`.
*   `tests/test_masks.py`: Тесты для `src/masks.py`.
*   `tests/test_processing.py`: Тесты для `src/processing.py`.
*   `tests/test_utils.py`: Тесты для `src/utils.py`.
*   `tests/test_widget.py`: Тесты для `src/widget.py`.

### Подход к тестированию:

*   **Фикстуры:** Используются для подготовки тестовых данных (`tests/conftest.py`).
*   **Параметризация:** Применяется для проверки функций с различными наборами данных.
*   **Мокирование API:** Взаимодействие с внешним API курсов валют в тестах мокируется с использованием инструментов из стандартной библиотеки `unittest.mock` (`Mock`, `patch`), что позволяет тестировать модуль `external_api.py` без реальных запросов к сети.

### Запуск тестов:

1.  Для запуска всех тестов используйте команду (из корневой папки проекта, в активированном окружении `poetry shell`):
    ```bash
    pytest
    # или с использованием Poetry:
    poetry run pytest
    ```
2.  Для проверки стиля кода с помощью Flake8:
    ```bash
    flake8 src tests
    # или
    poetry run flake8 src tests
    ```
    Если `Flake8` находит ошибки стиля, исправьте их вручную или используйте автоформатирование, например, с помощью `black` (если установлен).
